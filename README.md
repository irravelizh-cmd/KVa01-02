# Лист и полка — генератор ссылок для книжной рассылки

Открой `index.html` из этой папки двойным щелчком. Всё работает из одного локального
файла, без интернета. Стили и логика находятся внутри `index.html`.

## Что делает генератор

- Берёт полный адрес страницы (обязательно с `http://` или `https://`).
- Заполняет три метки: `utm_source`, `utm_medium`, `utm_campaign`.
- **Удаляет все старые значения** этих трёх параметров и добавляет новые — по одному разу каждый.
- **Сохраняет** путь, все остальные параметры вместе с повторяющимися значениями
  (например, `ref=author&ref=second`) и фрагмент после `#`.
- Кириллица, пробелы, `&`, `+`, `?` внутри значений кодируются стандартными
  средствами браузера, а рядом показывается читаемая сводка с исходными значениями.

## Как пользоваться

1. Вставь адрес страницы из редакционного плана.
2. Введи источник, канал и кампанию.
3. Для ноябрьского письма можно нажать «Параметры ноябрьского письма» — подставятся
   `newsletter`, `email`, `november`, а введённый адрес останется на месте.
4. Нажми «Собрать ссылку», проверь адрес и сводку меток справа.
5. Нажми «Скопировать ссылку». Подтверждение появится только после успешного копирования.

Если браузер запретил доступ к буферу, появится подсказка, а текст в поле «Готовая ссылка»
остаётся доступным для выделения и ручного копирования.

## Важное поведение

- При любом новом вводе или нажатии пресета предыдущая ссылка и сводка исчезают,
  кнопка копирования блокируется — так в письмо не уйдёт старый результат.
- Если поле не заполнено или адрес неполный, подсвечивается конкретное поле,
  рядом объясняется проблема, ссылка и сводка очищаются.

## Проверенные примеры

| Что проверяли | Результат |
|---|---|
| `...?ref=author&ref=second&utm_source=old&...#series` | старые UTM удалены, `ref` сохранён дважды, `#series` на месте |
| Кампания «осень & книги» | в ссылке закодировано, в сводке читается целиком |
| Пустой адрес | ошибка под полем, ссылка пуста, копирование недоступно |
| Пресет | подставил `newsletter / email / november`, адрес не изменил |
| Изменение поля после сборки | предыдущая ссылка удалена |
